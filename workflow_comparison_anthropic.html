Multi-Model AI Workflow Architecture

Internal Solution Consultant Prototype

Layer 1 — User Interaction
👤
User / Solution Consultant
Enters a single prompt in VS Code terminal or command-line interface
Layer 2 — Orchestration Layer
Python Orchestration Script
compare_models.py  /  autonomous_comparison.py
Loads environment variables · accepts prompt input · manages workflow execution · handles API requests · formats and routes outputs
🔐 Secure Configuration
  • .env file
  • OPENAI_API_KEY
  • ANTHROPIC_API_KEY
  • truststore / SSL handling
Layer 3 — Model Execution Layer
OpenAI API
GPT Model
Sends prompt to GPT model and returns response
Same prompt sent · Independent response generation
Anthropic API
Claude Model
Sends prompt to Claude model and returns response
Same prompt sent · Independent response generation
Layer 4 — Response Processing Layer
Response Aggregation
Collects OpenAI and Claude outputs into a unified comparison structure, normalizing format for downstream evaluation
Evaluation / Judge Layer
Runs a comparison pass across both outputs
  • Clarity
  • Completeness
  • Tone
  • Practical usefulness
  • Overall recommendation
💡 Optional
Judge can be powered by a selected model using a rubric-based evaluation prompt for objective scoring
Layer 5 — Output Layer
Formatted Output Generator
Builds a structured side-by-side report and renders all results for consultant review
📄 HTML Comparison Report
  • Original prompt
  • OpenAI response
  • Claude response
  • Recommended winner
  • Summary reasoning
Business Value
Rapid side-by-side model comparison
Better prompt & model selection
Stronger demo preparation
Reusable internal evaluation workflow
Foundation for autonomous agent orchestration
